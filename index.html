自動同期（GitHub）

GitHub のトークンを入れると、○△× の記録があなたの GitHub（非公開の Gist）にも保存され、ほかの端末と自動でそろいます。トークンは端末ごとに1回入れるだけです。

トークンの作り方
  1. PC で github.com にログインし、右上のアイコン → Settings を開く
  2. 左メニューのいちばん下の Developer settings を開く
  3. Personal access tokens → Tokens (classic) を開く
  4. Generate new token → Generate new token (classic) を押す
  5. Note に「スペイン語サイトの同期」など分かる名前を入れ、Expiration（有効期限）を選ぶ
  6. Select scopes では gist だけにチェックを入れる（ほかは入れない）
  7. いちばん下の Generate token を押し、表示された ghp_ で始まる文字列をコピーする（この画面を離れると二度と表示されない）
  8. 下の欄に貼り付けて「接続する」を押す。ほかの端末にも同じトークンを貼り付ける

※ トークンはパスワードと同じように扱い、人に見せないでください。不要になったら、同じ画面からいつでも削除（無効に）できます。

ページを開いたときと、○△× を付けたときに自動で同期します。2台で別々に解いた場合は、問題ごとに新しい記録を残して合わせます。

引き継ぎコード（手動）

記録を1つのコードにして書き出します。メモなどに保存しておけばバックアップになり、別の端末で読み込めば記録を移せます。

「合わせる」は問題ごとに新しい記録を残します。「置き換える」はこの端末の記録を消して、コードの内容にします。
