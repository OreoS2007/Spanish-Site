未来と過去未来　Futuro y condicional
このページについて
小テストと同じ形式で、日本語に合うように（　）内の不定詞を適切な時制（点過去・線過去・未来・過去未来）に活用させる問題が 100問 あります。配布プリントと8課の未来・過去未来をもとに、第1回の点過去・線過去も混ぜて、毎回ランダムな順番で出題します。基本は 第2回 基礎 で確認できます。
  • 「🔀 並べ直す」を押すと、別の順番で解き直せます。各問題の解説の最初に、どの分類（①〜⑤）の問題かが出ます。
  • ______ をタップすると答え、ヒント をタップすると不定詞（主語がないときは主語も）が出ます。
  • ○△× を付けた問題は「今日の復習」に出ます。
📌 要点 Resumen
1. 活用：語幹は未来と過去未来で共通
語幹の作り方動詞 → 語幹
規則：不定詞そのままtomar- / comer- / vivir- / estar- / ir- / ser-
語尾の e・i を d にtener → tendr- / venir → vendr- / salir → saldr- / poner → pondr- / valer → valdr-
語尾の e を除くpoder → podr- / saber → sabr- / haber → habr- / querer → querr-
ce・ec を除くhacer → har- / decir → dir-

※ 語尾 ── 未来：-é, -ás, -á, -emos, -éis, -án ／ 過去未来：-ía, -ías, -ía, -íamos, -íais, -ían。過去未来は yo と él/ella/usted が同じ形（podría）なので、主語に注意。

2. 用法：未来を1つ過去にずらすと過去未来
未来過去未来
これから先のこと
Mañana lloverá.		過去から見た「その先」
Dijo que llovería.
今のことの推量「〜だろう」
¿Dónde estará ahora?		過去のことの推量「〜だったのだろう」
¿Dónde estaría anoche?
命令・禁止
No saldrás de aquí.		婉曲（丁寧）・仮定の結論
¿Podría…? / Me gustaría… / Yo, en tu lugar, no lo haría.

※ 伝える動詞が現在なら未来（Ana dice que vendrá）、過去なら過去未来（Ana dijo que vendría / Les prometí que haría…）。
※ 過去のことでも、確かな事実なら点過去・線過去（Eran las diez）、推量なら過去未来（Serían las diez：10時ごろだっただろう）。
